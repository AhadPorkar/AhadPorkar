## GraphBPMS in one paragraph

A low-code platform where organisations design processes in BPMN 2.0, build forms and reports without code, connect their existing databases and services, and run everything on their own infrastructure. I owned its architecture and release process: a five-layer ASP.NET/C# application on SQL Server, a process engine with versioning and a sandbox environment, a data-provider layer for SQL Server/Oracle/PostgreSQL/MySQL/REST/SOAP, Android/PWA offline apps with GIS, and a national level-1 product security evaluation. Documentation: [wiki.graphbpms.ir](https://wiki.graphbpms.ir/).
